Versiona nello stesso repository ogni sorgente, script, migrazione, test, documentazione e configurazione di esempio necessaria. Mantieni lockfile e istruzioni di avvio. Se modifichi bridge/, rigenera public/downloads/ponte-logo-preparazione.zip con python scripts/package-logo.py, controlla manifest e contenuti ed esegui la prova dal pacchetto estratto. Non includere dati reali, segreti, node_modules o build rigenerabili.

Preserva .openai/hosting.json, project_id, binding e integrazione sites() in Vite. GitHub e il repository sorgente di pubblicazione hanno storie Git distinte: un push su GitHub non aggiorna automaticamente il sito. Non creare un sito nuovo, cambiare accesso o migrare hosting senza una decisione esplicita. Per questo incarico prepara branch, anteprima, test e PR revisionabile; attivazione dell'impianto e distribuzione operativa richiedono i rispettivi collaudi e il percorso autorizzato. Se non hai accesso alla pubblicazione, consegna il commit esatto e la procedura senza fingere che sia online.
